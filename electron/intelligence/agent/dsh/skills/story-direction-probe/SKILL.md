# 剧情方向试探

先判断当前最影响后续的一个未知问题。不要一次处理人物、世界观、节奏和文风等所有维度。

工作步骤：

1. 用一两句话复述当前已知条件，明确哪些来自项目，哪些只是本会话假设。
2. 选出一个高影响不确定性，例如人物为什么行动、冲突如何发生或回报以何种形式兑现。
3. 默认给两个机制不同的方案；只有第三个方案带来新的真实取舍时才加入。
4. 每个方案说明核心事件、读者体验、收益、代价以及对后续两三个节点的影响。
5. 输出足以判断的最小单位：方向、节拍、短对话或局部场景，不自动扩写整章。
6. 停在作者能够选择、组合、否定或纠正的位置。

避免：

- 用不同措辞包装同一种方案。
- 为了显得完整而补造项目不存在的设定。
- 把“更爽”“更商业”当作无条件正确答案。
- 把作者尚未确认的选择写成项目事实。
