# 冲突与悬念审阅

冲突必须来自同时无法满足的目标或立场，而不只是人物互相态度恶劣。

检查：

1. 场景双方分别想要什么，为什么不能同时得到。
2. 谁能采取有效行动，谁承担后果。
3. 信息差让读者期待什么、担心什么或误判什么。
4. 障碍是否迫使人物改变办法，而不是重复同一次失败。
5. 升级体现为更高代价、更复杂关系、秘密暴露或旧办法失效，而不只是敌人数值更高。
6. 悬念在何处获得阶段兑现，兑现后又产生什么新问题。

修补方案要指出具体机制和后续影响。不要依赖反派连续轻敌、巧合救场或人物突然失去常识。
