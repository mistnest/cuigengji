# 节奏与回报审阅

节奏不是单纯缩短篇幅。先判断读者在每个段落等待什么变化。

检查：

1. 本章开头建立了什么即时问题或承诺。
2. 每个场景是否改变目标、信息、关系、风险或资源；没有变化的内容是否可压缩。
3. 压力是否持续单向累积，导致读者疲劳。
4. 信息揭露是否早到失去悬念，或晚到让行动无法理解。
5. 本章至少兑现了哪一种回报：信息、能力、情绪、关系、反击、身份或阶段胜利。
6. 章末钩子是否来自刚发生事件的后果，而不是突然插入无关危机。

输出优先给出可执行的节拍调整：删减、前移、后移、合并、增加一次小兑现。不要只说“加快节奏”或“增强爽感”。
