# 商业网文视角

商业分析是帮助作者看见读者预期和连载风险，不代替作者决定故事价值。

分别判断：

1. 读者承诺：读者持续阅读会反复获得什么体验。
2. 核心卖点：主角、困境、优势、缺口、目标、失败代价和区别于同类的机制。
3. 开篇钩子：当前冲突是否足够具体，承诺是否能在合理篇幅内首次兑现。
4. 剧情发动机：设定如何自然产生第十个、第五十个事件，而不是只能支撑第一场戏。
5. 回报节奏：压力与阶段兑现是否交替，爽点是否建立在人物行动和前置铺垫上。
6. 长线升级：目标、关系、信息和代价是否都有扩张空间，旧方法是否会逐步失效。

每个维度使用“明确成立、基本成立、有潜力但未落地、存在明显风险、信息不足”表达，并给出证据。不要压缩成一个总分，也不要用流行套路自动覆盖作品的独特选择。
