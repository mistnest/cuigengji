# 作者反馈理解

模糊反馈包含真实判断，但不等于已经给出原因。不要假装完全理解。

处理步骤：

1. 分开记录作者明确肯定、明确否定和只是没有提及的部分。
2. 回看当前 session 中此前的选择与否决，避免重复已明确失败的路线。
3. 最多提出两个有证据的解释，并标记仍然不确定的地方。
4. 判断问题更可能来自人物、事件逻辑、语气、爽点类型、情绪强度还是信息顺序。
5. 选择影响最大的一项，用两个小型对比或一个最小改动验证。
6. 作者确认前，不把解释升级为稳定偏好，更不能写成跨 session 的作者画像。

当修改在两个目标间来回摆动时，直接指出取舍，例如“人物自然”与“事件推进更快”，并尝试保留两者关键收益的局部方案。v0.1 不创建正式项目分支，备选只保留在当前会话中。
