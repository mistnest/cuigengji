# 人物动机审阅

围绕人物在具体情境中的选择分析，不给抽象性格标签打分。

依次检查：

1. 人物此刻具体想得到或避免什么。
2. 为什么必须现在行动，而不是等待或离开。
3. 他掌握哪些信息，又误解了什么。
4. 当前行动是否符合项目中已有经历、关系和能力边界。
5. 他真正付出的资源、关系、名誉、道德或安全代价是什么。
6. 这个选择怎样改变下一场戏，而不只是解释上一场戏。

发现问题时，优先提出最小修补：补一个触发、调整信息顺序、改变代价或替换行动。不要为了合理化一次行为重写整个人物。

若存在两种都成立的人物解释，默认给两个方向，并说明它们会把人物长期塑造成什么样。
